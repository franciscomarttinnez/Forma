Contexto del Proyecto - FORMA
Descripción General

Forma es una aplicación web moderna enfocada en el fitness y el entrenamiento personalizado mediante Inteligencia Artificial.

La aplicación busca reemplazar la experiencia de buscar rutinas genéricas en internet ofreciendo planes completamente personalizados según las características, objetivos y limitaciones de cada usuario.

El objetivo no es simplemente generar una rutina, sino crear la experiencia de tener un entrenador personal digital disponible en todo momento.

El proyecto será utilizado como pieza principal de mi portfolio profesional, por lo que el foco está puesto tanto en la calidad técnica como en la experiencia de usuario.

No quiero una aplicación que parezca un proyecto universitario; quiero que se sienta como un producto real que podría lanzarse al mercado.

Filosofía del Producto

Forma debe transmitir simplicidad.

El usuario no debería sentirse abrumado con cientos de opciones.

Toda la experiencia debe ser clara, intuitiva y agradable.

La IA debe hacer el trabajo pesado.

El usuario solamente responde algunas preguntas y obtiene una rutina lista para comenzar a entrenar.

Toda modificación posterior debe ser extremadamente sencilla.

Objetivo Principal

Crear una aplicación que permita a cualquier persona obtener una rutina de entrenamiento completamente personalizada utilizando Inteligencia Artificial.

La rutina debe adaptarse a:

objetivos del usuario
nivel de experiencia
disponibilidad semanal
equipamiento disponible
lesiones
molestias
preferencias personales
ejercicios a evitar

Posteriormente el usuario podrá modificar esa rutina tanto manualmente como mediante nuevas instrucciones a la IA.

Experiencia Esperada

Quiero que la aplicación se sienta moderna, rápida y profesional.

Debe tener una experiencia similar a productos como Linear, Notion, Raycast o Apple Fitness.

La navegación debe ser simple.

Las animaciones deben ser suaves.

La interfaz debe ser limpia.

Cada interacción debe sentirse cuidada.

Público Objetivo

La aplicación está dirigida a personas que:

quieren comenzar el gimnasio
entrenan en casa
buscan organizar mejor sus entrenamientos
desean una rutina adaptada a sus necesidades
no saben cómo estructurar un plan de entrenamiento

No está orientada a fisicoculturistas profesionales sino al usuario promedio.

Flujo Principal

El recorrido ideal del usuario es:

Crear una cuenta o ingresar.
Completar un cuestionario inicial.
La IA genera una rutina personalizada.
El usuario visualiza la rutina organizada por días.
Puede expandir cada día para ver sus ejercicios.
Puede abrir cualquier ejercicio para ver su descripción, músculos trabajados y una animación o GIF demostrativo.
Puede editar la rutina manualmente o pedirle a la IA que la modifique.
Guarda automáticamente todos los cambios.

Todo el flujo debe sentirse natural y sin fricción.

Rol de la Inteligencia Artificial

La IA es el núcleo del producto.

No es un chatbot.

Debe comportarse como un entrenador personal.

Será responsable de:

generar rutinas
adaptar ejercicios
modificar entrenamientos existentes
responder solicitudes del usuario relacionadas con su plan
respetar lesiones y restricciones
explicar brevemente por qué propone determinados cambios

La IA siempre debe devolver información estructurada para facilitar su procesamiento.

Diseño

El diseño debe ser minimalista.

Debe priorizar:

mucho espacio en blanco
tipografía limpia
tarjetas modernas
bordes redondeados
animaciones discretas
excelente legibilidad

No quiero interfaces sobrecargadas.

Cada pantalla debe tener un propósito claro.

Identidad Visual

La aplicación utiliza el nombre Forma.

El logo principal es la letra F estilizada en color naranja, diseñada específicamente para este proyecto.

Debe utilizarse como identidad principal de la aplicación.

La paleta principal gira alrededor de:

naranja
blanco
negro
grises

El diseño debe transmitir energía, salud, simplicidad y modernidad.

Escalabilidad

Aunque inicialmente el proyecto estará enfocado en rutinas de entrenamiento, la arquitectura debe permitir incorporar nuevas funcionalidades sin necesidad de grandes refactorizaciones.

En futuras versiones podrían agregarse módulos como:

seguimiento del progreso
estadísticas
historial de entrenamientos
nutrición
planes alimenticios generados por IA
cálculo de calorías y macronutrientes
registro de peso corporal
rachas de entrenamiento
sincronización entre dispositivos
recordatorios
recomendaciones inteligentes

La arquitectura debe pensarse desde el principio para soportar este crecimiento.

Objetivo del Proyecto

Este proyecto será la pieza principal de mi portfolio como desarrollador Frontend.

Quiero demostrar conocimientos en:

React
TypeScript
arquitectura escalable
integración con APIs
autenticación
consumo de Inteligencia Artificial
diseño UI/UX
manejo de estado
componentes reutilizables
buenas prácticas de desarrollo

La prioridad no es terminar rápido, sino construir una aplicación con calidad profesional que pueda impresionar tanto a reclutadores como a otros desarrolladores.
